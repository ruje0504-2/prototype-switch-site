03 Install

You need a Switch capable of running homebrew, plus your own copy of the PC game data.

STEP 1

Prepare the console

Atmosphère environment and a microSD card. This project ships no game content or assets.

STEP 2

Place the data

Unpack your own PC copy into game/ on the SD card; movies go to game/Movies.

STEP 3

Run

Copy prototype-runtime.nro into switch/ and launch from the Homebrew Menu. Gamepad only.

Current builds default to GPU skinning; build with PROTO_GPU_SKINNING=OFF to switch back to CPU skinning.

Planned distribution: NRO and direct-install NSP (you must own the game) — not released yet, stay tuned.

04 FAQ

What game data do I need? Are assets included?

No assets are included. Only the homebrew code (NRO) is distributed; you must own the PC version. Release packages contain no original game files.

Why no DLSS / ray tracing / FSR2?

Tegra X1 has no tensor cores, no RT cores and no FP8 / cooperative-matrix / VK_NV_cuda_kernel_launch. Hardware ray tracing and the DLSS fast path are impossible, and DLSS 5 is not an upscaler anyway. FSR2/3 need motion vectors and history buffers, which cost more than they give here; we use FSR1 RCAS plus render-resolution tiers.

Why isn't it 60 FPS?

Around 46–49 FPS at stock clocks on device, limited by single-threaded render recording (~20 ms/frame). Numbers come from device logs, are not normalized across clocks, and are not a performance promise.

Is this an emulator or Wine?

No. It is a native ARM64 program: a custom Vulkan renderer, custom resource parsers and custom game logic reading the original data. Unlike Wine / Box64 / FEX compatibility layers.

Will the source be released? Is a PC version planned?

The source may be released later, depending on the graphics backend: if the project switches to NVN (Nintendo's proprietary graphics API, subject to NDA), the source cannot be published. The current backend is Vulkan NVK. A PC version is not planned; distribution is NRO builds for Switch.

Is this legal?

The project contains only original code and tools, no game assets, and bypasses no DRM or copy protection. You must legally own the game. Not affiliated with Activision or Radical Entertainment.
