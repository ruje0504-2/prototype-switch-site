# 项目主页（docs/site）

单文件静态页，参考 `ngb-hurricane-patch` 的信息结构（hero + 下载、特性、状态/路线、安装、FAQ、更新日志、免责声明），
内容取自本仓库当前状态（轮次 850 / 交付 844）。

**注意：源码发布取决于后端——若后续转 NVN（任天堂专有 API，NDA 限制）则无法公开；页面不包含任何源码/仓库链接。** 当前发布形式为 NRO 构建。

## 本地预览

```bash
open docs/site/index.html
```

## 发布

任意静态托管即可，与源码仓库是否公开无关：

- Cloudflare Pages / Netlify / Vercel：上传 `docs/site/` 目录；
- 或私有仓库的 GitHub Pages（需 Pro 才支持私有 Pages）。

自定义域名可选；页面无外部依赖，可直接单文件托管。

## 需要替换的占位

- **下载按钮**：`#install` 目前指向页面内安装说明；发布 NRO 后把
  `<a class="btn primary" href="#install">` 改成实际下载地址（网盘 / Release / 对象存储）。
- **数字**：轮次/提交/进度/NRO 大小写在 HTML 顶部 chips 与「进度与路线」面板里，
  每次发布前按 `docs/current.md` 更新。
- **截图**：参考站有 `.shots` 区块；本页暂未放截图，可在「已接通的原生实现」后加
  `<img>`（建议 1280×720 PNG，实机截图需标注版本）。

## 设计说明

- 主题贴近《虐杀原形》：近黑底 `#060507`、骨白 `#ece5d8`、血红 `#c8102e` / `#7c0a1d`，
  高亮色 `--vein #e0253c`；
- Hero 使用淡淡描边的 `PROTOTYPE` 巨型字 + 红色径向光晕 + 扫描线，卡片/时间线/按钮统一血红；
- 无外部字体/图片/JS 依赖，单文件即可托管；
- 中文为主，标题保留英文副标；FAQ 用原生 `<details>`，无脚本也能展开；
- FAQ 已写明"源码可能发布、若转 NVN 则无法公开、不计划 PC 版"。
